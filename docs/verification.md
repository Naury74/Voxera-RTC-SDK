# 검증 기록

Voxera를 실제 기기와 에뮬레이터에서 어디까지 확인했는지 정리한 문서입니다. 단위 테스트와 화면 테스트(Robolectric)는 CI가 매번 돌리므로 여기에는 사람이 직접 돌려 본 것만 적습니다.

- **Pass**: 직접 돌려서 기대대로 동작한 것
- **Pass (단위 테스트)**: 기기에서 재현할 방법이 없어 테스트로만 확인한 것
- **NOT RUN**: 아직 확인하지 못한 것. 이유를 함께 적었습니다.

## 시험 환경

| 구분 | 내용 |
| --- | --- |
| 실기기 | Galaxy Z Fold7(SM-F966N, Android 16) 접은 화면과 펼친 화면, Galaxy Buds2 |
| 에뮬레이터 | Pixel 프로필 API 26, 30, 31, 33, 34, 35, 36. 폴더블 프로필(Pixel 9 Pro Fold, API 36.1) |
| 통화 서버 | 로컬 `livekit-server --dev`, LiveKit Cloud(`wss://`) |
| 상대 참가자 | 에뮬레이터 두 대 사이 통화, Fold7과 에뮬레이터 사이 통화(인터넷 경유), LiveKit CLI 데모 봇, LiveKit Python SDK 참가자, LiveKit Meet와 같은 판의 웹 채팅 코드 |
| 빌드 | debug와 release(R8). 성능은 release |

## 성능과 메모리

### Fold7 펼친 화면 (1968×2184, 120Hz, release)

`cmd package compile -m speed` 뒤 데모 장면마다 15초 동안 `dumpsys gfxinfo`로 쟀습니다. 15초에 약 1776프레임이라 120Hz를 유지합니다.

| 장면 | 끊긴 프레임 | 프레임 p50/p90 | GPU p50/p90 |
| --- | --- | --- | --- |
| 9명 3×3 격자 | 0.00% | 8 / 9ms | 8 / 8ms |
| 4명 2×2 격자 | 0.00% | 9 / 9ms | 8 / 9ms |
| 1:1 상대 전체 화면 | 0.06% | 16 / 17ms | 16 / 16ms |
| 12명 두 쪽 | 0.00% | 17 / 17ms | 16 / 17ms |

1:1과 12명 장면은 GPU 시간이 격자의 두 배지만 끊긴 프레임은 거의 없습니다.

### Fold7 접은 화면 (debug, 조작 막대가 보이는 정지 상태)

| 화면 | 프레임 p50 | 프레임 p90 |
| --- | --- | --- |
| 오프라인 4명 데모 | 6~7ms | 8~9ms |
| 실통화 1:1 영상(30fps) | 6~9ms | 11~12ms |

영상 위에 유리가 보이는 동안에는 영상 프레임마다 블러를 다시 해서, 블러가 없던 이전 화면보다 프레임마다 3~4ms가 더 듭니다. 영상 통화에서는 조작 막대가 4초 뒤 숨으므로 통화 내내 드는 비용은 아닙니다. 접은 화면의 release 측정은 하지 못했습니다(NOT RUN).

## 확인 방법

같은 확인을 다시 할 때 쓴 방법입니다.

- **TalkBack이 읽는 문장**: TalkBack 설정 > 고급 > 개발자 설정에서 로그 수준을 VERBOSE로 두면 logcat에 `Speaking fragment text="..."`로 읽은 문장이 나옵니다(Google TalkBack 기준. 삼성 TalkBack은 남기지 않습니다).
- **TalkBack 항목 넘기기**: adb로 넣은 키와 터치는 TalkBack이 받지 않습니다. `adb shell hid -`로 USB 키보드를 등록해 Alt+→/←/Enter를 보내거나, HID 터치스크린(Digitizer Touch Screen)을 등록해 손가락 쓸기와 두 번 탭을 보냅니다.
- **프레임 시간**: 에뮬레이터는 `-gpu host`로 띄워야 GPU 시간이 실제 값으로 나옵니다. release 빌드에 `cmd package compile -m speed`를 한 뒤 `dumpsys gfxinfo`로 잽니다.
- **다른 SDK 참가자**: LiveKit Python SDK로 반응(`voxera.reaction`), 채팅(`lk.chat`), 세로·가로 영상, 트랙 없는 참가자 여럿을 만들어 넣었습니다.
- **로컬 실통화**: `livekit-server --dev`에 에뮬레이터는 `ws://10.0.2.2:7880`으로, 실기기는 `adb reverse`로 붙습니다. 평문 연결은 debug 빌드에서만 엽니다.
